# wlr-task-desktop

[![No Maintenance Intended](http://unmaintained.tech/badge.svg)](http://unmaintained.tech/)

A program to display minimized windows like Windows 3.x for Wayland compositor supports zwlr_foreign_toplevel_manager_v1 and zwlr_layer_shell_v1 protocols.

Wrote in rush in less than two weeks (until 2026-11-10) so the code currently needed to be cleaned up.

Tested on Arch Linux (Linux Kernel 7.2.14-arch1-1) with labwc 0.20.2
